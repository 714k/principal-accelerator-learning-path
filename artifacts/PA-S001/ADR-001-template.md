# ADR-001 — P0 public-product boundaries

Status: Proposed — LEARNER-OWNED

## Context

P0 currently publishes a concise portfolio under `apps/portfolio/` and the bilingual
Principal Accelerator Learning Site from `site/` through the inherited `apps/book/`
static renderer. The initial Node + TypeScript generator is explicitly experimental.

## Options

1. Retain separate portfolio and Learning Site products with the current minimal generator.
2. Retain the product boundary while adopting a justified static-site framework later.
3. Another option proposed and justified by the learner.

# Competency Matrix

Initial levels must be established from evidence. Do not invent starting mastery.

Do not require a standalone upfront diagnostic interview. Establish and refine levels progressively from normal session evidence: concept explanations/checks, learner-owned implementation, debugging, operation, design decisions, artifacts, tests and measurements.

## Mastery definitions

-   L1 Explain
-   L2 Implement
-   L3 Operate
-   L4 Decide
-   L5 Lead

## Rule

A competency level should be backed by evidence from completed sessions.
A checklist alone is insufficient.

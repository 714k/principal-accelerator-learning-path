## Progression policy

Progress status is non-blocking.

- `Completed`: sufficient evidence for current goals.
- `Partial`: useful evidence exists but some goals remain open.
- `Revisit`: concepts/evidence should be revisited.
- `Not started`: no recorded evidence yet.

None of these statuses prevents starting another session.

If a later session depends on incomplete prior material, record the dependency/revisit and continue using the minimum bridge needed.

Do not implement unlock logic based on session completion.

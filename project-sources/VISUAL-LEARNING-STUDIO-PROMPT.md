# Prompt reutilizable — Visual Learning Studio v12

Genera nuevamente solo el Visual Learning Studio de la sección actual, siguiendo Sources 14 y 16 v12. Conserva el contenido aprobado; no reautorices la sesión ni prepares un handoff de Codex.

Renderiza componentes visuales realmente interactivos en la conversación, con instrucciones breves, controles y respuestas dinámicas:

- Mapa mental: grafo, nodos seleccionables y resaltados, definiciones, ejemplos y relaciones.
- Flashcards: preguntas y respuestas explicadas, giro, anterior/siguiente y contador; cobertura local.
- Simulador: controles de variables/escenarios, salida y estado reactivos, explicación técnica de éxito/error/límites.
- Explorador de arquitectura: grafo etiquetado, selección de componente, resaltado de dependencias y panel de contratos/responsabilidades.
- Matriz: criterios/pesos ajustables, puntuaciones base y cálculo explicado, ranking/gráficas que se actualizan, supuestos y trade-offs.

Tema principal: los cinco recursos; cada subtema: mapa, tarjetas y al menos uno de simulador/explorador/matriz. Studio global adicional. Usa conceptos locales; no inventes datos empresariales, etiqueta hipótesis. No sustituyas widgets con código, tablas estáticas, promesas ni fallbacks. Si no se puede renderizar alguno, declara la limitación y no lo cuentes. Comprueba que los controles reaccionen y no declares completo lo que falta. Muestra únicamente el Studio solicitado.
